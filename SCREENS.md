# Diary App — UX Flow & Screen Specs

> ТЗ для дизайн-макетів. MVP: локальне зберігання, без Notion sync.

---

## Загальна навігація

```
┌─────────────────────────────────────────┐
│  [S1: Home]  ←──────────────────────────┤
│       │  натиснути запис                │
│       ↓                                 │
│  [S4: Entry Detail]                     │
│                                         │
│  [S1: Home] → кнопка запису             │
│       ↓                                 │
│  [S2: Recording] → Стоп                 │
│       ↓                                 │
│  [S3: Bottom Sheet] → Зберегти          │
│       ↓                                 │
│  [S4: Entry Detail]  або  [S1: Home]    │
│                                         │
│  [S1: Home] → «Всі записи»             │
│       ↓                                 │
│  [S5: Entries List]                     │
└─────────────────────────────────────────┘
```

**Навігація:** немає bottom tab bar. Перехід між екранами через:
- Кнопка запису → S2
- Натиснути картку → S4
- Посилання "Всі записи" → S5
- Кнопка назад / свайп → попередній екран

## S1 — Home

**Призначення:** точка входу. Швидкий запис або перегляд останніх записів.

### Лейаут

```
┌──────────────────────────────┐
│                              │  ← safe area top
│  Diary              [⚙]     │  ← назва + іконка налаштувань
│                              │
│ ┌──────────────────────────┐ │
│ │  Розчарування через...   │ │  ← картка запису
│ │  засмучення · надія      │ │
│ │  2:14  ·  Рефлексія · Ранок │
│ └──────────────────────────┘ │
│                              │
│ ┌──────────────────────────┐ │
│ │  Гарна прогулянка вранці │ │
│ │  радість                 │ │
│ │  1:03  ·  Щоденник · Ранок │
│ └──────────────────────────┘ │
│                              │
│       [ Всі записи → ]       │  ← лінк, якщо >3 записи
│                              │
│                              │
│            ●                 │  ← велика кнопка запису (v2)
│       Tap to record          │  ← підказка, зникає після 1-го запису
│                              │  ← safe area bottom
└──────────────────────────────┘
```

### Компоненти

**Хедер**
- Назва: "Diary" — Cormorant Garamond, 1rem, letter-spacing 0.26em, uppercase
- Іконка ⚙ (налаштування) — справа, з'являється в майбутній фазі

**Картка запису**
- Назва: DM Sans, 500, 15px, 2 рядки максимум (truncate)
- Теги настрою: кольорові chips малого розміру (засмучення · надія)
- Мета-рядок: `2:14  ·  Рефлексія  ·  Ранок` — DM Sans 300, 12px, opacity 0.55
- Тап → S4 (Entry Detail)
- Свайп вліво → видалити (з підтвердженням)

**Список:** 3–5 останніх записів, без заголовку дати

**Посилання "Всі записи":** з'являється якщо є більше 3 записів

**Кнопка запису**
- Дизайн: `button-demo-v2.html`
- Позиція: центр по горизонталі, ~80px від низу (над safe area)
- Idle: дихаючі кільця (pulse rings)

### Стани
- **Порожній (0 записів):** замість списку — великий центрований текст "Твій перший запис" та підказка
- **Завантаження (є записи, завантажуються):** skeleton картки

## S2 — Recording

**Призначення:** активний запис голосу.

### Тригер
Натискання кнопки на S1 → плавний перехід (кнопка залишається на місці, решта екрану змінюється)

### Лейаут

```
┌──────────────────────────────┐
│                              │
│                              │
│                              │
│           0:00               │  ← таймер (Cormorant Garamond, ~72px)
│                              │
│    ▁ ▂ ▄ ▃ ▅ ▂ ▁ ▃ ▄ ▂     │  ← waveform (live, анімований)
│                              │
│                              │
│                              │
│            ●                 │  ← кнопка (recording state з v2)
│         Записується          │
│                              │
└──────────────────────────────┘
```

### Компоненти

**Таймер**
- Шрифт: Cormorant Garamond Light, ~72px
- Формат: `0:00` → `1:23` → `10:00`
- Анімація появи: fade in + translateY(-12px) при старті запису

**Waveform**
- Живі бари що реагують на гучність мікрофона (Web Audio API `AnalyserNode`)
- 20–30 барів, різна висота, плавна анімація
- Колір: `rgba(30, 16, 40, 0.4)` — темний plum напівпрозорий

**Кнопка**
- Переходить у recording state (з v2): пурпурний glow, пришвидшені кільця, стоп-іконка
- Натискання → зупиняє запис → показує S3

### Перехід
- З S1 → S2: кнопка залишається нерухомою, фон/контент fade
- Натискання стоп → кнопка повертається в idle state, знизу виїжджає S3

## S3 — Review (post-recording, повний екран)

**Призначення:** після зупинки запису користувач бачить текст і поля, правит їх і зберігає. Повернутись до запису не можна, тому це повноцінний екран, а не sheet. Демо: `design/transcript-screen-demo.html`.

### Лейаут (зверху вниз)
1. Шапка: ✕ (видалити, з підтвердженням) · «Новий запис» / «Відновлений запис» + дата.
2. Аудіо-плеєр (play/pause, хвиля, тривалість) — сегменти грають підряд.
3. Прогрес у два кроки: Транскрибація → Аналіз і поля.
4. Світла підкладка з контентом: назва (поле) · перемикач «Оброблений / Оригінал» · текст (поле) · чіпи настрою, емоційного стану, тегів (прибрати × / додати +) · згортка «Ще поля» (тип, час доби, фізичний стан, контекст, проект — лише читання).
5. Липка панель знизу (safe-area): «Переписати» · «Зберегти».

### Стани (`#review[data-s]`)
- `transcribing`: скелетони назви й тексту.
- `analyzing`: сирий текст уже видно (лише читання), поля — скелетони.
- `ready`: усе редагується, «Зберегти» активна.
- `error`: картка помилки, «Зберегти» → «Повторити». Аудіо лишається в IndexedDB.
- `saving`: кнопка «Зберігаємо…».

### Переходи
- **Зберегти** → екран закривається, запис з'являється в списку на S1.
- ✕ і **Переписати** питають підтвердження (sheet), бо відкидають запис; «Переписати» одразу запускає новий запис.
- Відновлена чернетка (`recoverDraft`) відкривається на цьому ж екрані.
- Зберігається відредагований текст; `raw_text` — оригінал Whisper.

## S4 — Entry Detail

**Призначення:** повний перегляд одного запису.

### Лейаут

```
┌──────────────────────────────┐
│  ← Назад                    │  ← хедер з back кнопкою
│                              │
│  Рефлексія · Ранок           │  ← eyebrow (тип + час доби)
│  Розчарування через          │  ← назва (великий)
│  непродуктивний день         │
│                              │
│  😔 Поганий  · 🏃 Нейтральний│  ← емоційний + фізичний стан
│                              │
│  засмучення · розчарування   │  ← теги настрою
│  невдоволення · надія        │
│                              │
│  ─────────────────────────   │
│                              │
│  Вчора я був дуже            │  ← транскрипція (відредагована)
│  засмучений, адже цілий      │
│  день, який міг витратити    │
│  на роботу, провів на...     │
│                              │
│  ─────────────────────────   │
│                              │
│  Контекст                    │  ← мета-секція
│  Налаштування опалення       │
│                              │
│  Проект                      │
│  Система опалення            │
│                              │
│  Теги                        │
│  опалення · насос · ремонт   │
│                              │
│  ▶  ▁▂▄▃  2:14              │  ← компактний аудіо плеєр
│                              │
│  19 жовтня 2026, 8:18        │  ← дата
│                              │
└──────────────────────────────┘
```

### Компоненти

**Eyebrow:** `Рефлексія · Ранок` — DM Sans 300, 12px, uppercase, opacity 0.55

**Назва:** Cormorant Garamond, 28–32px, text-wrap: balance

**Стан стікери:** 2 пігулки в ряд (емоційний + фізичний)
- Колір залежить від значення: Поганий = теплий коричневий, Хороший = зелений і т.д.

**Теги настрою:** маленькі chips без фону, з border

**Текст транскрипції:** DM Sans 400, 16px, line-height 1.7, читабельно

**Мета-секція:** label + value в 2 колонки, дрібний шрифт

**Аудіо плеєр:** внизу, компактний

**Кнопка редагування:** в хедері (іконка олівця) — для майбутньої фази

### Стани
- `processing` (ще не готово): назва-placeholder, текст показує spinner
- `ready`: повний контент
- `error` (транскрипція не вдалась): показує тільки аудіо + кнопку "Спробувати ще"

## S5 — Entries List

**Призначення:** повний список всіх записів з фільтрацією.

### Лейаут

```
┌──────────────────────────────┐
│  ← Назад         Записи     │  ← хедер
│                              │
│  🔍 Пошук...                 │  ← поле пошуку
│                              │
│  [Всі] [Рефлексія] [Подія]   │  ← filter chips (горизонтальний scroll)
│  [Ідея] [Щоденник]           │
│                              │
│  ── Жовтень 2026 ──          │  ← розділювач по місяцю
│                              │
│ ┌──────────────────────────┐ │
│ │  Розчарування через...   │ │
│ │  засмучення · надія      │ │
│ │  2:14  ·  Рефлексія · Ранок │
│ └──────────────────────────┘ │
│                              │
│ ┌──────────────────────────┐ │
│ │  Гарна прогулянка вранці │ │
│ │  радість                 │ │
│ │  1:03  ·  Щоденник · Ранок │
│ └──────────────────────────┘ │
│            ...               │
└──────────────────────────────┘
```

### Компоненти

**Пошук:** повнотекстовий по назві та тексту (локальний, без API)

**Filter chips:** горизонтальний scroll. Фільтр по `entry_type`.
- Активний chip: темний фон (plum), текст cream
- Неактивний: прозорий з border

**Розділювачі:** `── Жовтень 2026 ──` між місяцями

**Картка:** та сама що на S1

**Порожній стан (після фільтрації):** "Нічого не знайдено"

## Transitions & Animations

| Перехід | Тип |
|---|---|
| S1 → S2 (старт запису) | Кнопка залишається, контент fade out/in |
| S2 → S3 (стоп) | Sheet виїжджає знизу (spring, 400ms) |
| S3 → S1 (зберегти) | Sheet виїжджає вниз, новий запис з'являється в списку |
| S1/S5 → S4 (деталь) | Slide left (стандартний iOS push) |
| Назад | Slide right |
