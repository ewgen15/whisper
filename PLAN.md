# Whisper — план розробки

## Статус: MVP запущений ✅

Голосовий щоденник. Записуєш голос → транскрипція → автоматична структуризація → зберігається в базу.

---

## Поточна архітектура

```
iPhone (Tailscale)
  │
  ├── PWA: https://ewgen15.github.io/whisper/
  │         GitHub Pages → docs/
  │
  └── Backend: https://homeserver.tail54ecf6.ts.net
                Tailscale Funnel + X-API-Key → міні PC → Docker
                ├── POST /transcribe  (faster-whisper, language)
                ├── POST /enrich      (gpt-4o правка + GPT-4o-mini поля, edit_level)
                ├── GET  /stats       ← documents (календар і графік настрою)
                ├── POST /save        → Supabase + Notion + вектор
                ├── GET  /entries     ← Supabase
                ├── PATCH/DELETE /entries/{id}  (синхронно з Notion і вектором)
                └── GET  /health
                          ↓
                    Supabase PostgreSQL
                    (entries, documents, embeddings)
```

## Окремий трек: «Карта дня» (концепція сну) 🧪
> **Розмежування.** Усе вище — основний щоденник (запис → розбір → збереження → заміна n8n). Цей розділ — **експериментальний трек**, що надбудовується над ним: нічого з нього не блокує фази 2–5 і не змінює поточну поведінку застосунку. Позначка: `[карта]` у задачах, якщо вони потрапляють в інші розділи.
> **Залежності від основного треку:** `POST /search` (Фаза 4), список/дані з `documents` (див. «Покращення»), `documents`/`embeddings` з Фази 3.
> **Конфлікт із поточними правилами:** зараз аудіо на сервері не зберігається (лише текст; аудіо лишається в IndexedDB). Крок 5 це змінює — перед ним оновити `CLAUDE.md`/`ARCHITECTURE.md` і вирішити, де лежатимуть файли та як їх бекапити.

### Ідея
Раз на день (~04:00, нічний батч) система «бачить сон» про користувача на основі RAG і вранці віддає карту: образ + одне питання-провокація. Три шари:
- **Образ** (таро-шар): символ домінантної теми
- **Дзеркало**: образ збирається з реальних сигналів із записів
- **Питання** (провокація): одна фраза, що виводить з автоматизму

### Модель «сну» → Whisper
1. **Залишки дня:** фрагменти записів за 1–3 дні, зважені за емоційним зарядом
2. **Переплітання:** RAG шукає семантично схожі записи з минулих місяців і з'єднує зі свіжими
3. **Логіка вимкнена:** генерація уникає буквальності (метафора, символ, сюрреалістичне поєднання)
4. **Емоції керують:** тон записів задає палітру, світло, атмосферу
5. **Синтез:** LLM збирає все в один образ + питання

### Аудіо-аналіз настрою (без GPU, нічним батчем)
1. Акустичні ознаки (librosa / openSMILE): висота, гучність, темп, паузи
2. Емоційна модель (emotion2vec / wav2vec2) на CPU
3. Тон за транскриптом через LLM
- Порівняння завжди з **власним базовим рівнем голосу**, а не з абстрактною нормою

### Стан на зараз
- Є історична база голосових у Telegram (з часів бота)
- У Notion лежать транскрипти + посилання на ці повідомлення
- Whisper PWA поки не зберігає аудіо
- GPU на сервері немає

### Покроковий план
Етапи A–C корисні й без «карти» (дані про голос), D — власне карта.

**A. Аудіо-дані**
- [ ] 1. Зв'язка аудіо ↔ Notion: зіставляти за часом (дата й час запису)
- [ ] 2. Витягти аудіо з Telegram: Desktop → Export chat history → тільки Voice messages, JSON (альтернатива: скрипт через Bot API, якщо є `file_id`)
- [ ] 3. Базовий профіль голосу: акустичні ознаки по всій історії, середнє й розкид
- [ ] 4. Збагачення записів: дописати в Notion/БД метрики голосу й настрій до кожного запису
- [ ] 5. Зберігати аудіо у Whisper (Opus, з id і часом поруч із транскриптом), щоб база росла далі (див. конфлікт вище)

**B. Сигнали**
- [ ] 6. Оцінка «емоційного заряду»: тон голосу + тон тексту + повторюваність теми

**C. Збирання матеріалу**
- [ ] 7. «Залишки дня»: відбір фрагментів за 1–3 дні + RAG-пошук схожого з минулого (спирається на `POST /search`)

**D. Карта**
- [ ] 8. Генерація карти: промпт «сну» → образ + питання (формат образу — відкрите питання)
- [ ] 9. Нічний запуск (~04:00): cron на сервері, збереження карти, показ у PWA вранці
- [ ] 10. Ітерації: підкручувати вагу сигналів і стиль за відчуттям
